About NoteJS

NoteJS is a simple, in-browser JavaScript editor and runner. The app is made entirely in vanilla JavaScript, HTML, and CSS - all contained in a single file.

It provides a basic, uncluttered interface for writing and executing JavaScript code. Features include full-app cohesive themes (including Night Owl, Darcula, Material, Dracula, Monokai, Nord, Solarized, Tomorrow Night, Ambiance, Eclipse, and IntelliJ), syntax highlighting, intelligent code completion, smart live auto-indentation, code formatting, interactive line-referenced error reporting, a console for output, and full file save/open operations with native autosave.

Keyboard Shortcuts:

  • Cmd/Ctrl+Enter: Run code
  • Cmd/Ctrl+S: Save file
  • Cmd/Ctrl+Shift+S: Save As...
  • Cmd/Ctrl+O: Open file
  • Shift+Alt+F / Cmd+Option+F: Format code
  • Tab: Indent or autocomplete
  • Shift+Tab: Outdent line / selection
  • Ctrl+Space: Show autocomplete

Autosave: When enabled in the toolbar and a file is opened or saved, changes are automatically saved directly to the file on disk as you type.
